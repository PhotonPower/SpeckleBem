# Reference data

Small reference datasets used by the validation suite (kept under 1 MB each):

- `mie_ag_4um_500nm_rcs.csv` – bistatic RCS of a 4 µm Ag sphere at 500 nm (Mie), normal and parallel planes (Phase 2)
- `rough_surface_seed42_L10um.txt` – rough-surface regression reference (Phase 1): rms, estimated Lc, full-map checksums (Σz, Σz², Σ(i+2j)·z) and the heights at 16 grid points of `generate_gaussian_height_map` for seed 42, L = 10 µm, mesh 50 nm, σ = 50 nm, Lc = 500 nm (read by `tests/unit/test_rough_surface.cpp`). After a deliberate generator change, regenerate it from the repository root with the hidden Catch2 test case: `SPECKLEBEM_REGEN_OUTPUT=tests/data/rough_surface_seed42_L10um.txt build/release/tests/specklebem_unit_tests "[.regen]"` (without the variable the content is printed to stdout).
- `tetra_ascii.stl` – closed tetrahedron (1 mm legs, metres) as ASCII STL with deliberately wrong facet normals (mesh I/O tests)
- `tetra.obj` – the same tetrahedron as OBJ with comments, ignored statements and `a/b/c`, `a/b`, `a//c` face forms
- `tetra_v41.msh` – the same tetrahedron as Gmsh 4.1 ASCII with non-contiguous node tags, skipped sections and point/line elements
- `broken_count.stl` – binary STL whose stored triangle count (5) does not match its 4 records (must be rejected)
- `broken_face.obj` – OBJ whose last face (line 9) references vertex 7 of 4 (must be rejected)
- `broken_version.msh` – Gmsh 2.2 file (must be rejected: only 4.1 is supported)

Large data (meshes > 1 MB, field cubes) are never committed; they are
regenerated by `scripts/` or downloaded from a release asset.

# Reference data

Small reference datasets used by the validation suite (kept under 1 MB each):

- `mie_ag_4um_500nm_rcs.csv` – bistatic RCS of a 4 µm Ag sphere at 500 nm (Mie), normal and parallel planes (Phase 2)
- `rough_surface_seed42_L10um.npz` – height map for a reproducible rough-surface regression test (Phase 1)

Large data (meshes > 1 MB, field cubes) are never committed; they are
regenerated by `scripts/` or downloaded from a release asset.
